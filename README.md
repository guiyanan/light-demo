# 光明乳业 · 小红书洞察驱动的新品概念生成 Demo

从小红书笔记和评论中提炼消费者需求，生成新品概念和包装效果图的演示项目。

## 首次准备（只做一次）
1. 安装并打开 **Docker Desktop**。
2. 打开项目文件夹（文稿/光明demo）里的 `.env` 文件（访达中按 `Cmd+Shift+.` 可显示隐藏文件），
   把三个接口的地址和密钥粘贴进去，保存。各项含义见文件里的中文注释。

## 每次启动
在访达里双击 **`start.command`**。它会：
1. 拉取最新代码（`git pull`）
2. 构建并启动网页（`docker compose up --build`）
3. 自动打开浏览器 http://localhost:8501

第一次构建要下载依赖，可能需要几分钟。要停止时关闭终端窗口即可。

> 如果双击后提示"无法打开"，在 `start.command` 上点右键 → 打开，确认一次即可。

## 怎么用（网页左侧菜单，按顺序 4 步）
1. **① 数据抓取**：输入关键词（如「低温酸奶」），点「开始抓取」。从小红书搜 40 篇候选，按评论数挑 10 篇，
   保留每篇的评论（自动过滤水评论）。约 1–2 分钟，消耗聚道云点数。
2. **② 需求洞察**：选刚才那次抓取，点「提炼需求」。Kimi 提炼 5 条消费者需求，每条附消费者原话（程序会逐字核对出处，
   广告帖的原话标「广告」）。约 1–3 分钟。
3. **③ 新品概念**：点「生成概念」，得到 3 个光明新品概念（品名、卖点、人群、原料、包装规格、营养估算）。约 1–3 分钟。
4. **④ 产品图与导出**：
   - 点「生成图片」，3 张包装效果图同时画，并在右侧排好概念信息，约 1–3 分钟；某张不满意可单独「重画」。
   - 点「生成报告和压缩包」，再点两个下载按钮：
     - **报告（HTML）**：双击用浏览器打开，不需要联网；浏览器里「打印 → 存为 PDF」即得每个概念一页的 PDF。
     - **图片压缩包（zip）**：3 张合成展示图 + 3 张 AI 原图。

每一步的结果都会保存，下次打开选同一次抓取即可直接查看，不会重复花钱。某一步失败时页面会显示原因和「编号」，
点「重试这一步」即可，不影响已完成的步骤；把编号发给开发者可在日志里查到详细原因。

> 效果图和营养数据都是 AI 生成，仅供内部讨论，不是最终设计；左上角预留了 logo 位置，等客户提供 logo 后再放。

## 接口检查
网页左侧菜单 →「接口检查」，分别点击三个按钮测试聚道云、Kimi、生图接口。
也可以在命令行运行：`docker compose run --rm web python -m app.diag`

## 日志和运行结果在哪里
- `logs/app/`：运行日志；`logs/error/`：错误日志（含出错位置）
- `logs/diag/`：接口检查的原始响应（已脱敏）
- `logs/build/`：每次启动的构建输出
- `data/runs/`：每次运行的结果（`export/` 里是导出的报告和压缩包）
